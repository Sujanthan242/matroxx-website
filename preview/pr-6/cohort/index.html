// Cohort & Process

How the cohort model works, step by step.

Matroxx builds the core product for $0. The partner covers infrastructure, licences and third-party services at cost — never marked up. Selection is competitive.

// 01 — How it works

01Week 0–1

Brief

You send a project brief. Matroxx replies, and a technical call tests whether the build is a fit.

02Weeks 1–2

Selection + discovery

Fit check, scope lock, and a stack and architecture sketch — the build is agreed before it starts.

03Weeks 3–7

Build

Vertical slices, demoed each week, so the partner sees progress as it happens.

04Week 8

Hardening

Tests, Quality Gate review, a security pass, and documentation.

05Week 9

Launch + handover

Deploy, handover, and a short support window.

06After launch

Case study

Published only with partner approval.
